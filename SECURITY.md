# Security policy

HandoverLab is a simulator that runs locally on files you give it; it opens no network service
except the optional dashboard (`handoverlab gui`), which listens on the local machine by default.

## Supported versions

Security fixes are made for the latest release.

## Reporting a vulnerability

Please do not open a public issue. Use **Security > Report a vulnerability** on the GitHub page of
the repository to send a private report. You will get an answer within two weeks.
